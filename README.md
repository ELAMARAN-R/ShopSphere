# ShopSphere

A responsive e-commerce web application built using React.js.

## Features

- Product listing
- Product details
- Product search
- Shopping cart
- Cart quantity management
- Wishlist
- Checkout form
- Order confirmation
- LocalStorage persistence
- Responsive design

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- LocalStorage
- REST API

## Project Overview

ShopSphere is a frontend e-commerce application designed to demonstrate React development skills, component-based architecture, routing, state management, and browser storage.
